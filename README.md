# Hi, I'm Nándor Bereczki 👋

I'm a frontend developer based in Szeged, Hungary.  
I focus on building clean, fast, and accessible web interfaces – mostly using React, Next.js, TypeScript, and plain HTML/CSS when needed.

I currently collaborate with [Binary Birds](https://binarybirds.com) as a freelance developer, working on production-grade web applications that often integrate with server-side Swift backends.

Some areas I particularly enjoy:
- Building custom UI components and handling complex frontend logic
- Designing templates for the [Toucan static site generator](https://github.com/BinaryBirds/Toucan)
- Improving developer experience and keeping the codebase maintainable
- Creating lightweight tools to solve very specific problems
